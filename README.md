# SDE Interview Preparation

A curated checklist of Data Structures & Algorithms (DSA), system design and behavioral questions for software engineering (SDE) interview preparation, organised by topic and difficulty.

## Repository contents

| File | Description |
| --- | --- |
| [`SDEInterviewGuide`](SDEInterviewGuide) | Plain-text list of 77 interview questions grouped by topic and difficulty (Easy / Medium / Hard). Some questions are tagged with companies that have asked them (e.g. Amazon, Google, Microsoft, Facebook). |
| [`LICENSE`](LICENSE) | Mozilla Public License 2.0 |

The guide contains question names only; it does not include problem statements, solutions or code.

## Topics covered

- Arrays and Strings (e.g. Two Sum, Longest Substring Without Repeating Characters, Trapping Rain Water)
- Linked Lists (e.g. Merge Two Sorted Lists, Reverse Nodes in k-Group, Copy List with Random Pointer)
- Stacks and Queues (e.g. Min Stack, Sliding Window Maximum, LRU Cache)
- Trees and Binary Search Trees (e.g. Validate BST, Level Order Traversal, Serialize and Deserialize Binary Tree)
- Graphs (e.g. Number of Islands, Course Schedule, Network Delay Time)
- Sorting and Searching (e.g. Merge Sort, Binary Search, Search in Rotated Sorted Array)
- Dynamic Programming (e.g. Climbing Stairs, Coin Change, Edit Distance)
- Greedy Algorithms (e.g. Jump Game, Gas Station)
- Backtracking (e.g. Generate Parentheses, N-Queens, Sudoku Solver)
- Miscellaneous (e.g. Rotate Image, First Missing Positive)
- System Design (URL Shortener, Social Media Feed, Parking Lot)
- Behavioral questions

## How to use

1. Open `SDEInterviewGuide` and pick a topic.
2. Work through the questions from Easy to Hard, solving each on a platform such as LeetCode in the language of your choice.
3. Track your progress, review time/space complexity, and revisit questions you struggled with.
